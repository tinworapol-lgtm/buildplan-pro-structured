# Release Readiness Phase 10

Phase 10 adds release metadata and handoff documents without changing runtime behavior.

## Added

- `release-manifest.json`
- `CHANGELOG.md`
- `docs/PRODUCT_ROADMAP.md`
- `docs/RELEASE_CHECKLIST.md`

## Why

The project is now split into JS modules, CSS modules, services, contracts, and config. A manifest and checklist make it easier to package, review, and hand off as a subscription product.
